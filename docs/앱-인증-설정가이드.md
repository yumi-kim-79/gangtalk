# 앱 인증 설정 가이드 (Mac / 콘솔 작업)

카카오·애플 로그인과 SMS 인증을 실제로 동작시키려면 코드 외에 아래 설정이 필요합니다.
**순서대로 진행하세요. 1~2 를 안 하면 앱이 빌드되지 않습니다.**

---

## 1. 의존성 설치 + pod install (필수)

새로 추가된 네이티브 모듈: `@react-native-kakao/core`, `@react-native-kakao/user`,
`@invertase/react-native-apple-authentication`, `@react-native-firebase/app-check`,
`@react-native-async-storage/async-storage`

```bash
cd ~/GangTalk/app
npm install
npm run ios:setup
```

> 클라우드 리눅스 VM 에서 npm install 을 돌리면 macOS 전용 `fsevents` 가 비워집니다.
> Mac 에서 `npm install` 을 다시 돌리면 복구됩니다.

---

## 2. Cloud Functions 배포 (필수)

카카오 로그인용 `kakaoSignIn` 함수가 추가됐습니다. 배포 전에는 카카오 로그인이 실패합니다.

```bash
cd ~/GangTalk
npm run deploy:functions
```

## 3. 카카오 개발자 콘솔

https://developers.kakao.com → 내 애플리케이션

1. **앱 키** → `네이티브 앱 키` 복사
2. **플랫폼 등록**
   - Android: 패키지명 `com.appmonster.gangtalk` + 키 해시 등록
   - iOS: 번들 ID `com.appmonster.gangtalk`
3. **카카오 로그인 활성화** → ON
4. **동의항목** → 닉네임(필수), 카카오계정(이메일) — 이메일은 선택으로 둬도 동작합니다

### 키 해시 구하기 (Android)

```bash
# 디버그 (개발용)
keytool -exportcert -alias androiddebugkey \
  -keystore ~/GangTalk/app/android/app/debug.keystore \
  -storepass android -keypass android | openssl sha1 -binary | openssl base64
```

릴리스 키스토어를 만든 뒤에는 그 키의 해시도 등록해야 합니다.

### 앱에 키 넣기

`app/.env` 파일을 만들고 (git 에 커밋되지 않습니다):

```
KAKAO_APP_KEY=여기에_네이티브_앱_키
WEB_URL=https://gangtox.com
ADMIN_WEB_URL=https://gangtalk815.com
```

### iOS 추가 설정

`app/ios/GangTalk/Info.plist` 에 아래를 넣어야 카카오톡 앱으로 전환됩니다.

```xml
<key>CFBundleURLTypes</key>
<array>
  <dict>
    <key>CFBundleURLSchemes</key>
    <array><string>kakao여기에_네이티브_앱_키</string></array>
  </dict>
</array>
<key>LSApplicationQueriesSchemes</key>
<array>
  <string>kakaokompassauth</string>
  <string>kakaolink</string>
</array>
```

### Android 추가 설정

`app/android/app/src/main/AndroidManifest.xml` 의 `<application>` 안:

```xml
<activity android:name="com.kakao.sdk.auth.AuthCodeHandlerActivity" android:exported="true">
  <intent-filter>
    <action android:name="android.intent.action.VIEW" />
    <category android:name="android.intent.category.DEFAULT" />
    <category android:name="android.intent.category.BROWSABLE" />
    <data android:host="oauth" android:scheme="kakao여기에_네이티브_앱_키" />
  </intent-filter>
</activity>
```

## 4. 애플 로그인 (iOS)

소셜 로그인을 넣으면 **App Store 심사 4.8 에 따라 애플 로그인이 필수**입니다.

1. Apple Developer → Certificates, Identifiers & Profiles → App ID `com.appmonster.gangtalk`
   → **Sign In with Apple** 체크
2. Xcode → GangTalk 타겟 → Signing & Capabilities → **+ Capability → Sign In with Apple**
3. Firebase 콘솔 → Authentication → Sign-in method → **Apple 사용 설정**

---

## 5. App Check (SMS 인증에 필요)

`sendSmsCode` / `verifySmsCode` 는 `enforceAppCheck: true` 라 App Check 없이는 호출이 거부됩니다.

1. Firebase 콘솔 → App Check → 앱 등록
   - iOS: **App Attest** (또는 DeviceCheck)
   - Android: **Play Integrity**
2. 개발 중에는 디버그 토큰이 필요합니다 — 앱 실행 시 콘솔에 찍히는 토큰을
   Firebase 콘솔 → App Check → 앱 → 디버그 토큰 관리에 등록

> App Check 를 아직 설정하지 않았다면 SMS 인증 단계에서
> "문자 인증 서버 설정이 필요합니다" 안내가 뜹니다. 그 외 기능은 정상 동작합니다.

---

## 6. Firebase Authentication 사용 설정

Firebase 콘솔 → Authentication → Sign-in method

- **이메일/비밀번호** 사용 설정
- **Apple** 사용 설정 (4번 참고)
- 카카오는 커스텀 토큰이라 별도 설정 불필요
