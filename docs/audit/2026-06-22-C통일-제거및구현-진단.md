### 4-3. firestore.rules — 자가가입 통과 검증

`stores create` (`:111-112`):
```

```
→ 본인 uid 로 자가 create ✓

`users create` (`:67-70`):
```
match /users/{uid} {
  allow read: if isOwner(uid) || isAdmin();
  allow create, update, delete: if isOwner(uid) || isAdmin();
}
```
→ 본인 uid 로 자가 create ✓

`meta/counters` (`:337-350`):
- create (첫 1회) / update (+1 정확) — `_fbSignupBiz` 의 transaction 통과 ✓
