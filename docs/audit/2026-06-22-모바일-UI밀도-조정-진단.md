# 모바일 UI 밀도 조정 진단 — 위쪽 컴팩트 + 페이지 간 통일

날짜: 2026-06-22
목표: 현황판/가게찾기/제휴관/강톡의 위쪽 영역(검색창/핫이슈/배너/카테고리/카드)을
컴팩트하게 줄여 아래 리스트가 더 보이도록 + 페이지 간 "동일한 크기" 보장
범위: 진단 전용. 코드 / CSS / PR / 배포 변경 0건.

## 0. TL;DR — 현재 위쪽 영역이 차지하는 높이 (모바일 412px 기준)

| 페이지 | 영역 | 현재 높이 합 |
|---|---|---|
| **현황판** (`/`) | 헤더(130) + 핫이슈(62 + 14m) + 카테고리(~88) | **~294px** |
| **가게찾기** (`/find`) | 헤더(130) + 핫이슈(62 + 14m) + 배너(180 + 8m) + 카테고리(~88) | **~482px** ← 거대 |
| **제휴관** (`/partners`) | 헤더(130) + 배너(180 + 12m) + 카테고리(~88) | **~410px** |
| **강톡** (`/chat`) | 헤더(64, no-search) + 슬라이더(180) + 커뮤니티 카드 2×130 + gap | **~530px** |

권장 컴팩트 후:
- 현황판 ~294 → **~228px** (-22%)
- 가게찾기 ~482 → **~370px** (-23%)
- 제휴관 ~410 → **~316px** (-23%)
- 강톡 ~530 → **~436px** (-18%)

세 페이지의 **공통 영역**(헤더/검색/카테고리)은 이미 통일됨. 페이지별 차이는 **배너 유무**(현황판은 핫이슈만, 가게/제휴는 배너) + 강톡 슬라이더가 큰 게 주요인.

### 4-2. "강남·하퍼 오른쪽 이동" — 진짜 원인

**마크업** (`StoreFinder.vue:238-242`):
```html
<div class="m-meta">
  <div class="name-row">
    <div class="m-name ellip">{{ s.name }}</div>
    <div class="m-sub ellip">ㅣ {{ s.region }} · {{ mapCat[s.category] }}</div>
  </div>
  <div class="ad-excerpt">...</div>
</div>
```

→ 마크업은 이미 `name-row` 안에 `m-name + m-sub` 가로 배치 의도

**CSS 누락** (`grep` 결과):
- `.name-row` 와 `.m-sub` **CSS 정의 없음** — sf-tops `:deep` scope 어디에도 없음
- 디폴트 `div` 는 block → **세로 쌓임** (사진 2번 증상)

**해결책 — CSS 1 블록 추가만으로 해결**:
```css
.sf-tops :deep(.name-row) {
  display: flex;
  align-items: baseline;
  gap: 6px;
  min-width: 0;
}
.sf-tops :deep(.m-name) {
  flex: 0 1 auto;
  max-width: 60%;          /* 긴 이름이 sub 를 밀어내지 않게 */
  overflow: hidden;
  text-overflow: ellipsis;
  white-space: nowrap;
}
.sf-tops :deep(.m-sub) {
  flex: 1;
  min-width: 0;
  font-size: 12px;
  color: #888;
  overflow: hidden;
  text-overflow: ellipsis;
  white-space: nowrap;
}
```

→ 마크업 변경 0, CSS 추가만으로 "업체명 + 강남·하퍼" 한 줄 가로 배치

## 9. 주의점

### 9-1. 배너 비율
- 현재 180px height + 100% width (12px - 16px 좌우 패딩) = 모바일 412px 기준 비율 **약 2.2:1**
- 140px 로 줄이면 비율 **약 2.9:1**
- 마케팅에서 배너 만들 때 이 비율을 고려해야 함 → **사용자에게 확인 필수**

### 9-2. 한글 라벨 잘림 (카테고리 44px 원형)
- 현재 11px 폰트 + 원형 48px → "가라오케" (4자) ~40px 차지, 안 잘림
- 원형 44 + 10.5px 폰트 → 안전권 유지 (단 사용자 디바이스 폰트 설정에 따라 다를 수 있음)
- 대안: 원형만 44 로 줄이고 폰트는 11 유지 (안전)

### 9-3. "강남·하퍼 가로 배치" 의 이름 너무 김
- "강남톡방" 같은 짧은 이름 + "강남·텐카페" 6자 → 한 줄에 들어감
- "ABCDEFGHIJKL" 같은 긴 영문 이름 + "비강남·가라오케" → 자르기 필요
- 권장 `.m-name max-width: 60%` 로 sub 영역 확보

### 9-4. 점프 방지 토큰 (`--app-header-total`)
- 페이지 진입 시 점프 차단용 min-height
- 헤더 padding 줄이면 토큰도 함께 조정 필수 (안 그러면 빈 공간)

### 9-5. 강톡 슬라이더는 별도 디자인 결정
- 강톡의 가로 슬라이더는 4초 자동 전환 + 카운트 인디케이터 등 시각적 비중이 큼
- 다른 페이지의 배너와 함께 줄여도 되지만, 사용자 의도 확인 필요 (디자인 단독성)

### 9-6. 다크모드
- 모든 변경은 라이트 모드 기준
- 다크모드 보정 (예: `:root[data-theme="dark"]`) 도 동일하게 적용되므로 별도 작업 불필요
