## 1. 닉네임 "게스트" 표시

### 1-1. 가입 시점의 닉네임 흐름

**입력 (`src/pages/AuthPage.vue:113-120`)**:
```html
<label>닉네임</label>
<input
  class="auth-input"
  v-model="nick"
  placeholder="표시될 이름 (한글,영어 가능)"
  required          ← 빈 값 차단 (브라우저 검증)
/>
```

**전달 (`AuthPage.vue:618-624`)**:
```js
await me.signupUser({
  email: emailTrim,
  password: password.value,
  nick: nick.value.trim(),
  refCode: refInput || undefined,
})
```

**저장 (`src/store/user.js:411-485 _fbSignupUser`)**:
```js
tx.set(userRef, {
  type: 'user',
  profile: {
    email,
    nickname,           ← AuthPage 에서 전달된 nick 그대로
    nick: nickname || '',
    ...(hasNickname ? { nicknameLower: nickname.toLowerCase() } : {}),
    uid,
  },
  ...
}, { merge: true })
```

→ **가입 시 닉네임은 사용자 입력값 그대로 저장**. `'게스트'` 같은 기본값으로 폴백하는 코드 **없음**.

### 1-3. `src/store/auth.js:60` — **데드코드**

```js
this.user = {
  id: 'u_demo', role: 'female', email,
  nickname: '게스트',           ← 데모용 임시 로그인

```
- 저장 키 = `gt_auth_v1` (현재 운영 키 `app:user:auth` 와 별개)
- **`@/store/auth` import 한 파일 0개** (`grep "@/store/auth" src/` → 0 hits)
- → **사용되지 않는 데드코드**. `'게스트'` 저장 출처가 아님

### 1-4. `useMyPageCore.js:1648-1656` — **표시용 폴백 8순위**

```js
const nick = computed(() => {
  return (
    p.nickname ||      // 1순위: Firestore profile.nickname
    p.nick ||          // 2순위: profile.nick
    p.name ||          // 3순위: profile.name
    c.nickname ||      // 4순위: company.nickname
    c.manager ||       // 5순위: company.manager
    fromLocal ||       // 6순위: localStorage('user:nick'/'nickname')
    emailId ||         // 7순위: 이메일 @ 앞부분
    '게스트'           // 8순위: 모든 폴백 실패 시
  )
})
```
- `me.auth.value` 의 profile/company/email 이 **모두 비어있을 때만** `'게스트'` 표시
- **저장하지 않음** — UI 컴퓨티드 only
- 사용자가 로그아웃 상태 또는 LS_AUTH 가 reset 된 상태일 때 표시

### 1-5. "이 계정만인지" 판단

| 후보 | 가능성 | 근거 |
|---|---|---|
| 신규 가입 전반 기본값이 게스트 | ❌ | 가입 코드에 `'게스트'` 기본값 없음. 입력 필수 |
| 이 계정 (yusung090909) 가입 시 본인이 `'게스트'` 라고 입력 | ⚠️ 가능 | AuthPage 의 `<input required>` 가 빈 값만 막음 — `'게스트'` 입력은 통과 |
| LS_AUTH 의 nickname 자체는 비어있고, 마이페이지가 8순위 폴백으로 `'게스트'` 표시 | ⚠️ 가능 | `useMyPageCore.js:1655` 의 표시 로직. 사용자가 LS_AUTH 의 실제 값과 화면 표시를 혼동했을 수 있음 |
| 코드 어딘가에서 자동으로 `'게스트'` 저장 | ❌ | grep 으로 그런 코드 없음 확인 |

**결정적 확인 방법** (사용자 콘솔):
```js
JSON.parse(localStorage.getItem('app:user:auth')).profile.nickname
// '게스트'  → 본인이 가입 시 입력한 값
// undefined / '' / null → 마이페이지 8순위 폴백으로 표시
```

## 2. /biz/my-store 하단의 작은 배너

### 2-1. 정체 — **대표 이미지 미리보기**

`src/pages/admin/BizMyStorePage.vue:126`:
```html
<img v-if="form.thumb" :src="form.thumb" class="adm-thumb-preview" alt="대표 이미지" />
```
- 업로드한 가게 대표 이미지를 폼 하단에 작게 미리보기
- `form.thumb` URL 이 있을 때만 렌더 (조건 v-if)

### 2-2. CSS 정의 (`BizMyStorePage.vue:423-428`)
```css
.adm-thumb-preview{
  margin-top: 8px;
  max-width: 200px;
  max-height: 140px;

  object-fit: cover;
}
```

→ 사용자가 본 "작게 나오는 배너" 가 바로 이 `200×140` 박스.

### 2-3. 다른 화면 영향 범위


- **`.adm-thumb-preview` 클래스는 `BizMyStorePage.vue` 전용**
- `src/styles/admin.css` 등 공용 CSS 에 없음
- 다른 admin 페이지 / 회원 빌드 / 다른 컴포넌트 무관
- **이 화면 한 곳만 수정하면 됨** (공용 영향 0)
