### 1-4. 2줄 변경점

**방법 A — flex-wrap 만 추가 (최소 변경)**:
```css
.sf-cat-scroll{
  display:flex;
  flex-wrap:wrap;                /* ← 추가 */
  overflow-x:visible;            /* ← 변경 (스크롤 차단) */
  gap:14px 10px;                 /* 줄간격 약간 줄임 */
  /* 나머지 그대로 */
}
```
장점: 1줄 변경. 단점: 라벨 폭 차이로 줄당 칸 수 들쭉날쭉 (4-5 칸 섞임).

**방법 B (권장) — grid 5열 균일**:
```css
.sf-cat-scroll{
  display:grid;
  grid-template-columns:repeat(5, 1fr);
  gap:12px 8px;
  overflow:visible;
}
.sf-cat-item{
  min-width:0;                   /* grid 셀 폭 따름 */
  flex:initial;                  /* flex 속성 무효화 */
}
.sf-cat-label{
  white-space:nowrap;
  overflow:hidden;
  text-overflow:ellipsis;
  max-width:100%;
}
.sf-cat-expand{ display:none; }  /* wrap 모드에선 의미 없음 */
```
- 10개 / 5열 = 정확히 **2줄**
- 라벨 길이 무관 균일 격자
- 더보기(expand) 버튼은 wrap 시 의미 없으므로 숨김

### 1-5. 모바일 412px 칸 수 계산

`.page` padding-left/right = `var(--page-h-pad, 16px)` (`:2060`) → 좌우 32px 차감
가용 폭: 412 - 32 = **380px**

방법 A (flex-wrap):
- item 점유: `min-width 54px + gap 14px` ≈ 68px
- 380 / 68 ≈ 5.6 → 5칸 한 줄, 나머지 5칸 두 번째 줄
- **거의 정확히 2줄** (`bar(Bar)` 처럼 라벨 긴 칩이 한 칸 더 차지 가능)

방법 B (grid 5열): **정확히 5×2 = 2줄**, 모든 칸 균일

### 2-4. 2줄 변경점

**방법 A (flex-wrap)** — 동일 패턴:
```css
.pp-cat-scroll{
  display:flex !important;
  flex-wrap:wrap;                  /* 추가 */
  overflow-x:visible;              /* 변경 */
  gap:14px 10px;
  /* 나머지 그대로 */
}
```

**방법 B (grid 5열, 권장)** — `.cat-grid` 의 옛 룰을 살리고 `.pp-cat-scroll` 의 flex 강제를 꺼야 함:
```css
.pp-cat-scroll{
  display:grid !important;
  grid-template-columns:repeat(5, 1fr) !important;
  gap:12px 8px !important;
  overflow:visible;
  align-items:start;
}
.pp-cat-scroll .cat{
  flex:initial !important;
  min-width:0 !important;
}
.pp-cat-scroll .cat .lbl{
  white-space:nowrap;
  overflow:hidden;
  text-overflow:ellipsis;
  max-width:100%;
}
```
- `!important` 가 다수라 그대로 두면 `.cat-grid` 의 5열 룰이 안 살아남 — 방법 B 에서 모두 `!important` 로 다시 박아야 함
- `display:flex !important` 를 `display:grid !important` 로 바꾸는 게 가장 단순

### 2-5. 모바일 412px 칸 수 계산

가용 폭: 412 - 32 = **380px**

방법 A (flex-wrap):
- item 점유: `min-width 60px + gap 14px` = 74px
- 380 / 74 ≈ 5.1 → 5칸 / 5칸 = **거의 정확히 2줄**

방법 B (grid 5열): **정확히 5×2 = 2줄**

라벨 잘림 위험:
- 380 / 5 = 76px (한 칸 폭)
- 원형 아이콘 48px + padding → 라벨 가용 폭 ≈ 76px
- 한글 라벨 (예: `공동구매` 4글자 / 11px font) → 약 4×7 = 28px → 여유. 안전
- `cat-icon` 의 cat-ico-circle 이 라벨보다 넓을 일 없음 → 줄바꿈 없음

## 4. "2줄 고정" vs "wrap" — 정책 결정

| 정책 | 의미 | 권장 케이스 |
|---|---|---|
| **2줄 고정 (grid 5열, 방법 B)** | 정확히 N열 × 2행. 카테고리 ≤ 10 이면 안정 | 본 PR 권장 — 두 페이지 모두 10칩이라 5×2 균일 |
| **wrap 자연 (flex-wrap, 방법 A)** | 줄 수 = 콘텐츠 폭에 따라 자동. 일반적 2~3줄 | 카테고리 개수가 페이지마다 다르거나 추가 예정일 때 |

**카테고리가 늘어나는 경우 처리**:
- 방법 B (grid 5열) 에서 11개째 칩이 추가되면 3번째 줄에 1개만 떠 어색해질 수 있음 → 그 시점에 `repeat(6, 1fr)` 로 늘리거나 wrap 으로 전환
- 현재 양쪽 모두 9~10 개 고정이라 5열 5×2 가 최선
- StoreFinder 의 9 업종 카테고리는 늘어날 가능성 거의 없음 (가게 카테고리 = 업종)
- PartnersPage 의 9 partner 카테고리는 PR #99 의 `PARTNER_CATEGORIES` 모듈에서 관리 — 추가 시 같은 모듈만 수정하면 5×2 → 5×n 자동 적응 (단 grid 열 수도 같이 조정 필요)

## 6. 권장 변경 요약

### 6-1. StoreFinder
- `.sf-cat-scroll` — `display: flex` → `display: grid`, `grid-template-columns: repeat(5, 1fr)`, `overflow-x: auto` 제거 / `overflow: visible`, `gap: 12px 8px`
- `.sf-cat-item` — `flex: none` → `flex: initial`, `min-width: 0`
- `.sf-cat-label` — `white-space: nowrap; overflow: hidden; text-overflow: ellipsis; max-width: 100%`
- `.sf-cat-expand` — `display: none` (wrap 모드에선 의미 없음)
- `mpCategories` 데이터는 그대로

### 6-2. PartnersPage
- `.pp-cat-scroll` — `display: flex !important` → `display: grid !important`, `grid-template-columns: repeat(5, 1fr) !important`, `overflow-x: auto` → `overflow: visible`, `gap: 12px 8px !important`
- `.pp-cat-scroll .cat` — `flex: none !important` → `flex: initial !important`, `min-width: 0 !important`
- `.pp-cat-scroll .lbl` — `white-space: nowrap; overflow: hidden; text-overflow: ellipsis; max-width: 100%`
- `region-pop` 절대위치 좌표는 첫 칩 기준이라 그대로 동작 (검증 권장)

### 6-3. 옵션 — 더 작은 화면 (예: 360px) 보정
- 360px 폭에서는 한 칸 ≈ 65px → 라벨 잘림 가능

- 본 PR 에서는 5×2 만 적용해도 412px (현대 모바일 표준) 에서 안전
