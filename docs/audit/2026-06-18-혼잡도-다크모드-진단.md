### 1-2. 함수 — 사실은 혼잡도 계산 중

`MainPage.vue:998-1004`:
```js
function wifiText(s){
  const c = wifiColor(s)
  if (c === 'ok')   return '좋음'
  if (c === 'busy') return '나쁨'
  return '보통'
}
```

`MainPage.vue:2032-2047`:
```js
const wifiColor = (storeOrStatus)=>{
  if (!isRoomsBizReady.value) return 'mid'
  const st = typeof storeOrStatus === 'string'
    ? storeOrStatus
    : computeStatus(storeOrStatus || {})   // ← 혼잡도 계산
  if (st === '좋음' || st === '여유')  return 'ok'
  if (st === '보통')                    return 'mid'
  if (st === '나쁨' || st === '혼잡')   return 'busy'
  return 'mid'
}
```

`computeStatus` (`:1963-2030`) — 맞출방/전체방 비율 기반 혼잡도 자동 계산:
- ≥0.60 → '좋음'
- ≥0.30 → '보통'
- < 0.30 → '나쁨'

**즉**: 함수명/CSS 클래스명은 "wifi" 지만 **로직과 출력은 이미 혼잡도**. 사용자 혼동 유발 — 라벨 정정 필요.

## 2. 다크모드 토글

### 2-1. 인프라 — 이미 완비

#### A. 테마 store (`src/store/theme.js`, 39줄)

```js
const KEY = 'theme';

export function normalizeTheme(v) { /* 'dark|black' → 'black', else 'white' */ }
export function getTheme() { return normalizeTheme(localStorage.getItem(KEY) || 'white'); }
export function setTheme(v) {
  const t = normalizeTheme(v);
  localStorage.setItem(KEY, t);
  applyThemeToDom(t);
  window.dispatchEvent(new CustomEvent('themechange', { detail: t }));
  return t;
}
export function toggleTheme() {
  return setTheme(getTheme() === 'white' ? 'black' : 'white');
}
export function applyThemeToDom(v) {
  document.documentElement.setAttribute('data-theme', normalizeTheme(v));
}
export function attachThemeSync() {
  window.addEventListener('storage', ...);   // 다른 탭/창 동기화
}
```

저장: `localStorage.theme = 'white' | 'black'`
적용: `<html data-theme="white|black">` attribute
동의어: `light/white` = 라이트, `dark/black` = 다크
브로드캐스트: `themechange` CustomEvent + storage 이벤트
