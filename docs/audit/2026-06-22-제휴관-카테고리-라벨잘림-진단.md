## 0. TL;DR

- **사용자가 보는 "라벨 잘림" 의 진짜 원인은 PNG 아이콘 자체의 잘림** — 라벨 텍스트는 412px 폰에서 잘리지 않음
- `PartnersPage.vue:1611-1657` 에서 9 카테고리 PNG 아이콘 4개가 **컨테이너(.cat-icon width:32px) 보다 큰 background-size 강제**:
  - `ps` (성형외과) → `background-size: 35px` (컨테이너 32보다 +3)
  - `skin` (피부) → **50px** (+18 — 심한 잘림)
  - `fit` (피트니스) → **40px** (+8)
  - `deal` (공동구매) → **50px** (+18)
- 즉 아이콘 안의 그림이 우측/하단 잘림 → 시각적으로 "라벨 영역까지 답답함" 으로 보이는 인상
- 라벨 텍스트는 412px 기준 칸 폭 ~72.8px vs 4글자 한글 ~46px → **여유 26px, 잘림 0**
- 작은 폰 (≤360px) + active + 800 weight 4글자 한글 = 가로 ellipsis 발동 가능 (별개 위험)
- **스케일 축소 (cat-icon-size 40 → 더 작게) 는 PNG 잘림 악화** — 원형이 작아질수록 PNG 50px 이 더 튀어나옴
- **진짜 해결**: PNG `background-size` 를 컨테이너 폭 이하 (28~30px) 로 통일 + `.cat-icon` 폭을 원형 40 안의 36~40 로 늘림

## 2. 진짜 원인 — PNG 아이콘 `background-size` 오버라이드 (`PartnersPage.vue:1611-1657`)

### 2-1. 각 카테고리별 PNG `background-size` (개별 override)
| 카테고리 | 라벨 | `background-size` | 컨테이너 (32) 초과 |
|---|---|---|---|
| `ps` | 성형외과 | **35px** | +3px (살짝 잘림) |
| `skin` | 피부 | **50px** | **+18px (심한 잘림)** ← 가장 심함 |
| `beauty` | 미용 | (기본 contain) | 정상 |
| `nail` | 네일 | (기본 contain) | 정상 |
| `real` | 부동산 | (기본 contain) | 정상 |
| `fit` | 피트니스 | **40px** | **+8px (잘림)** |
| `deal` | 공동구매 | **50px** | **+18px (심한 잘림)** |
| `shop` | 상품관 | (기본 contain) | 정상 |
| `etc` | 기타 | (기본 contain) | 정상 |

→ **4개 (ps/skin/fit/deal) 가 컨테이너 32 보다 큰 PNG 강제** — `.cat-icon { width:32px; height:32px }` 안에서 background-position:center 로 가운데 정렬되며 **우측/하단 잘림**

### 2-2. 잘림 메커니즘
```
.cat-icon (32×32, overflow 기본 visible 이지만 background-clip 자동 적용)
  └ background-image: cat-skin.png
      background-size: 50px              ← 이미지 자체는 50px 로 렌더링
      background-position: center        ← 32 중앙에 50 정렬
      → 좌우 9px씩 잘림 (PNG 가 컨테이너 밖으로 튀어나가 사라짐)
```

### 2-3. 사용자 인식과의 연결
- 사용자 시점: 카테고리 칸 전체 = 원형 아이콘 + 라벨 한 묶음
- 원형 안 PNG 그림이 잘려 디자인이 "답답함/뭔가 잘림 느낌"
- 라벨 영역도 같이 답답하게 느껴짐 → 사용자는 **"라벨이 잘림"** 으로 표현
- 실제 라벨 텍스트는 잘리지 않음 (3. 참조)

## 3. 라벨 자체 — 412px 기준 잘림 0

### 3-1. 칸 폭 계산
- 페이지 폭 412px
- `.page` 좌우 padding `var(--page-h-pad, 16px)` × 2 = 32
- 콘텐츠 폭: 412 - 32 = **380px**
- 그리드: 5열 + `gap: 6px 4px` (행/열) → 열 사이 gap × 4 = **16px**
- 한 칸 폭: (380 - 16) / 5 = **72.8px**

### 3-2. 라벨 가용 폭
- `.cat padding: 0 !important` → 칸 전체가 라벨 폭
- `.lbl max-width: 100%` → **72.8px**

### 3-3. 4글자 한글 라벨 실제 폭 (10.5px, weight 600)
- 한글 1글자 ≈ font-size × 0.95 ~ 1.0 = **약 10~10.5px**
- "성형외과" = 4 × ~10.5 = **~42px**
- "피트니스" = 4 × ~10.5 = **~42px**
- "공동구매" = 4 × ~10.5 = **~42px**
- 칸 가용 72.8 vs 라벨 42 → **여유 30.8px, 잘림 0** ✓

### 3-4. Active 시 (font-weight 800) 폭
- bold 한글은 ~+10% → 42 × 1.1 = **~46px**
- 여전히 72.8 vs 46 → 여유 26.8px, 잘림 0 ✓

### 3-5. 작은 폰 (360px) 시뮬
- 콘텐츠 폭: 360 - 32 = 328
- 한 칸: (328 - 16) / 5 = **62.4px**
- 4글자 active 폭 ~46 vs 62.4 → 여유 16.4px, 잘림 0 ✓

→ **412px / 360px 모두 라벨 가로 잘림 없음**. ellipsis 발동도 없음.

### 3-6. 라벨 세로 잘림 점검
- `.lbl font-size: 10.5px; line-height: normal` (~1.2) = **box height 12.6px**
- `.cat` 에 height 제한 없음, overflow visible
- `.pp-cat-scroll` padding-bottom 8px → descender 잘림 0
- → 세로 잘림도 없음

## 5. 잘림이 어디서 발생하는지 (재정리)

| 가설 | 검증 | 결론 |
|---|---|---|
| (가) 아이콘 원이 커서 라벨 세로 공간 부족 | 원형 40 + gap 6 + 라벨 12.6 + padding 8 = **60+px**, `.cat` 무제한 → height 충분 | ❌ |
| (나) 라벨 폰트가 칸 폭보다 커서 가로 잘림 | 라벨 46 vs 칸 72.8 (412px) / 62.4 (360px) | ❌ 잘림 0 |
| (다) 라벨 컨테이너 height 고정 + overflow hidden | `.lbl` 에 height 없음, `.cat` 에 height 없음 | ❌ |
| (라) line-height 작아 descender 잘림 | line-height normal 1.2 + padding-bottom 8 충분 | ❌ |
| **(마) PNG background-size > 컨테이너 (32) → 아이콘 우측/하단 잘림** | `skin: 50px / deal: 50px / fit: 40px / ps: 35px` | **✅ 진짜 원인** |
| (바) 일부 active 4글자 + 360px 이하 = 라벨 ellipsis | 시뮬 결과 360px 도 여유 16px → 정상 | ⚠️ 더 작은 폰 (≤340px) 만 위험 |

## 7. 올바른 해결 방향

### 7-1. 권장 (PNG 아이콘 정상화) ★
```css
/* .cat-icon 폭 32 → 36 (원형 40 안의 90% 활용) */
.pp-cat-scroll .cat-icon{
  width: 36px;
  height: 36px;
  background-size: contain;   /* 기본 = 컨테이너 안 비율 유지 */
}

/* 개별 카테고리 background-size 오버라이드 제거 */
/* .cat-icon[data-type="ps"]    { background-size:35px } ← 제거 */
/* .cat-icon[data-type="skin"]  { background-size:50px } ← 제거 */
/* .cat-icon[data-type="fit"]   { background-size:40px } ← 제거 */
/* .cat-icon[data-type="deal"]  { background-size:50px } ← 제거 */
```

→ 모든 PNG 가 컨테이너 36×36 안에 contain 비율 유지로 정확히 들어감, 잘림 0

### 7-2. 또는 (background-size 통일)
```css
.cat-icon[data-type="ps"]   { background-size: 28px; }   /* 32 안에 여유 */
.cat-icon[data-type="skin"] { background-size: 28px; }
.cat-icon[data-type="fit"]  { background-size: 28px; }
.cat-icon[data-type="deal"] { background-size: 28px; }
```
- 단점: 다른 아이콘 (contain) 과 사이즈 불일치 → 일부 작아 보임
- 권장: 7-1

### 7-3. 라벨 자체는 건드릴 필요 없음
- 412px / 360px 모두 잘림 0
- 더 작은 폰 (≤340px) 대비라면 라벨 폰트 10 → 9.5 가능. 단 가독성 한계

### 7-4. active 800 weight 4글자 안전망 (선택)
```css
.pp-cat-scroll .cat.active .lbl{
  font-weight: 700 !important;   /* 800 → 700 (한글 bold 폭 5% 감소) */
}
```
