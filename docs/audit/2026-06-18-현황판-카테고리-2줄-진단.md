## 5. 5열 적용 결과 (모바일 412px)

- 페이지 패딩: `padding-left/right: max(var(--page-h-pad, 16px), env(...))` (`:2440-2441`) → 좌우 32px 차감
- 가용 폭: 412 - 32 = **380px**
- 한 칸 폭: 380 / 5 = **76px** (gap 8px 별도)
- 라벨 길이 검증:
  - 한글 4글자 (예: `가라오케`, `노래방`(3), `텐카페`(3), `텐프로`(3), `일프로`(3), `하퍼`(2), `쩜오`(2), `기타`(2), `전체`(2)) × 11px ≈ 22~44px
  - 특수: `바(Bar)` (괄호 포함 6글자) ≈ 50px → 76px 한 칸 안에 안전
- → **모든 라벨 잘림 없음**

10칩 / 5열 = **정확히 5×2 = 2줄 균일 격자, 빈칸 0**.

## 6. 권장 변경 (PR #101 패턴 그대로)

### 6-1. `.mp-cat-scroll`
- `display: flex` → `display: grid`
- `grid-template-columns: repeat(5, minmax(0, 1fr))` 추가
- `gap: 14px` → `gap: 12px 8px`
- `overflow-x: auto` → `overflow: visible`
- `-webkit-overflow-scrolling: touch` 삭제 가능 (스크롤 제거)
- `scrollbar-width: none` + `::-webkit-scrollbar` 룰은 무해 (남겨도 OK)

### 6-2. `.mp-cat-item`
- `flex: none; min-width: 54px` → `flex: initial; min-width: 0`

### 6-3. `.mp-cat-label`
- `white-space: nowrap; overflow: hidden; text-overflow: ellipsis; max-width: 100%` 추가

### 6-4. `.mp-cat-expand`
- `display: none` (격자 모드에서 의미 없음 — dead `expandCategories` ref 와 짝)
- 마크업/ref 자체는 그대로 두어도 무해 (변경 최소화 원칙)

### 6-5. 클릭/필터 로직
- `setType(c.key)` (`:1033`) 그대로
- `mpCategories` 데이터 그대로
- `type` ref 그대로
- **클릭/필터/상태 변경 0**
