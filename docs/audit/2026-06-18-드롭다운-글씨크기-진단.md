→ 모바일에서 select 자체 표시 글씨는 `16px` 강제. 이건 **select 의 닫힌 상태(현재 선택값) 표시** 의 크기.

### 2-3. **핵심 — 옵션 펼쳐졌을 때의 글씨는 CSS 무효**

네이티브 `<select>` 펼침 동작 (옵션 목록):
- **iOS Safari**: 화면 하단에서 올라오는 picker (drum-roll). 글씨 크기 OS 시스템 폰트 사이즈에 종속. CSS 영향 0
- **Android Chrome**: 가운데 dialog 형식 또는 dropdown. CSS 영향 거의 0 (브라우저별로 일부 가능)
- **데스크탑 (Chrome/Edge/Safari)**: 옵션 목록이 select 의 `font-size` 일부 반영. 그러나 한정적 (option 요소에 직접 font-size 지정해도 무시되는 환경 다수)
- **Firefox**: 데스크탑/안드로이드 모두 option font-size 일부 영향

사용자 환경이 모바일 (이 앱은 모바일 뷰 위주) 이면 **CSS 로는 옵션 목록 글씨를 키울 수 없음**.

## 4. 권장안 평가

### 4-1. A안: CSS font-size · height 확대

```css
/* 가능한 변경 */
.adm-field select {
  font-size: 18px;     /* 14 → 18 */
  height: 48px;        /* 40 → 48 */
}
@media (max-width: 768px) {
  .adm-field select { font-size: 18px !important; }
}
```

**효과 범위**:
- ✓ select 의 **닫힌 상태** (현재 선택값) 글씨 커짐
- ✓ select 박스 자체 크기 커짐 → 터치 영역 확대
- ✗ **펼쳤을 때의 옵션 목록 글씨는 변화 없음** (OS 가 그려서)

→ **A안만으로는 사용자 불만 해결 불가**. 옵션 목록 = 모바일에서 OS picker.

### 4-2. B안: 커스텀 드롭다운 컴포넌트로 교체

`<select>` 대신 listbox 패턴의 커스텀 드롭다운:
- 클릭 시 `<div class="dropdown-menu">` 가 펼쳐짐
- 각 `<div class="dropdown-option">` 의 font-size 완전 제어
- OS picker 가 아닌 직접 DOM 렌더 → CSS 100% 적용

장점:
- 옵션 목록 글씨 키울 수 있음
- 스크롤/검색/그룹화 등 확장 가능

단점:
- 구현/유지보수 비용
- 접근성 (키보드 navigation, aria, screen reader) 직접 처리 필요
- 모바일 큰 옵션 수 시 스크롤 어색할 수 있음

**대안 (B-경량)**: `<select size="N">` 으로 옵션 N개를 펼친 상태로 항상 표시 — 카테고리 9개라 시각적 부담은 있지만 OS picker 안 거침. 단 모바일에서도 OS 가 일부 영향 줄 수 있어 신뢰성 한정.

### 4-3. 절충안 — 옵션 수가 적으면 라디오 그룹

지역 4개 / 시급 유형 4개는 라디오 또는 칩(chip) 그룹으로 항상 펼쳐 표시 가능:
```html
<div class="adm-chip-group">
  <button v-for="r in regionOptions" :class="{ on: form.region === r }" @click="form.region = r">{{ r }}</button>
</div>
```
- font-size 완전 제어
- 카테고리 9개는 다소 빽빽하지만 가능

장점:
- 가장 단순
- 옵션 글씨 크기 자유
- B안보다 가벼움

단점:
- 옵션 많을 경우 화면 차지

### 5-3. CSS 만 키우는 임시 조치 (A안)

옵션 목록은 못 키워도 select 박스 자체와 닫힌 상태 글씨를 키우면 가독성 일부 개선:

```css
/* BizMyStorePage.vue:411 변경 (3개 admin 페이지에 영향) */
.adm-field select {
  height: 48px;
  font-size: 18px;
}
@media (max-width: 768px) {
  .adm-field select { font-size: 18px !important; }
}
```

→ 옵션 목록은 여전히 OS 가 그려 사용자 불만 완전 해소 안 됨. 그래도 닫힌 상태 가독성은 향상.
