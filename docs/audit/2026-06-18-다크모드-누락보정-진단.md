## 1. 제휴관 카테고리 아이콘 — PNG vs SVG 차이

- `c.iconSvg` = inline SVG (`mpCategories` 배열 안)

```css
  color:var(--muted, #999);    /* ← 핵심: 이 색이 SVG stroke 로 전달됨 */
  ...
}
```

**다크 보정** (`:2043-2047`):
```css
:root[data-theme="dark"] .sf-cat-ic,
:root[data-theme="black"] .sf-cat-ic{
  background:var(--surface, #1c1c1c);
  border-color:var(--line, #2a2a2a);
}
```

→ 다크 토큰 자동 반영:
- `--surface: #15161a` (어두운 배경)
- `--muted: #b7bac4` (밝은 회색 글자/SVG)
- **`currentColor` 가 다크 색을 자동 적용** → 잘 보임

**각 카테고리 PNG 매핑** (`:1598-1644`):


**active 시에는 흰색 처리 있음** (`:1422-1424`):
```css
.pp-cat-scroll .cat.active .cat-icon{
  filter: brightness(0) invert(1);   /* PNG 를 흰색으로 변환 */
}
```

**기존 다크 보정** (`:1646-1651`, `:1496-1497`):
```css
:root[data-theme="dark"] .cat-icon,

  border-color:#ddd;
  color:#ddd;                   /* ← PNG 라서 효과 0 */
}
:root[data-theme="dark"] .pp-cat-scroll .cat-ico-circle,
:root[data-theme="black"] .pp-cat-scroll .cat-ico-circle{
  /* 배경/테두리 보정만 — PNG 자체 색은 그대로 검정 */
}
```

→ **`color: #ddd` 가 PNG 에는 무효** (PNG 는 자체 색 보유). 다크 어두운 배경 (`--surface: #15161a`) 위에 **원본 검정 PNG** 가 그대로 → 안 보임.

### 1-3. 해결 — PartnersPage 의 PNG 에 다크 필터 1줄

**추가할 셀렉터**:
```css
:root[data-theme="dark"] .pp-cat-scroll .cat-icon,
:root[data-theme="black"] .pp-cat-scroll .cat-icon{
  filter: brightness(0) invert(1);    /* PNG 흰색 변환 */
}
```

위치 권장: `:1646-1651` 기존 다크 보정 블록 바로 다음. 또는 그 블록과 통합.

**active 와 충돌**:
- `.cat.active .cat-icon` 도 이미 `filter: brightness(0) invert(1)` (`:1422-1424`)
- 다크 모드 active 시: 핑크 그라디언트 배경 + 흰 PNG → 그대로 잘 보임
- 다크 비-active: 어두운 배경 + 흰 PNG → 잘 보임
- **충돌 없음**

**색 옵션 (선택)**: 흰색 (`brightness(0) invert(1)`) 대신 회색 톤 원하면:
```css
filter: brightness(0) invert(0.7);  /* 70% 흰 = 밝은 회색 */
```
→ 다크 톤 일관성 (다른 다크 아이콘이 `#b7bac4` 회색이므로 더 어울림)

### 1-4. 영향 범위

- `.pp-cat-scroll .cat-icon` 셀렉터: PartnersPage 단독 사용 (페이지 scoped style)
- `cat-icon` 자체는 다른 페이지에서 사용 안 함 (grep 검증 — 0건)
- 영향 0 — PartnersPage 카테고리 칩만 다크 보정
