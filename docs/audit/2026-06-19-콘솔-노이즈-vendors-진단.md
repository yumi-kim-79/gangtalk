function watchWithLabel(label, refOrQuery, next) {
  return onSnapshot(

### 1-3. 사용처 — `applyRoomsBiz` 폴백

`MainPage.vue:1219-1285`:
```js
function applyRoomsBiz(){
  const rbMap = roomsBiz.value || {}
  const agg   = labelsAgg.value || {}    // ← vendors 집계

  const out = bases.map((s) => {
    const byRb = rbMap[id] || null
    const byAg = agg[String(s.name || '')] || null    // ← vendors

    // 1) 맞출방 / 필요인원: rooms_biz → legacy stores (vendors 무관)
    const match = rbActive ? Number(byRb.rooms) : legacyMatch
    const persons = rbActive ? Number(byRb.people) : legacyPersons

    // 2) totalRooms: vendors → stores 폴백
    const totalRooms = Number(byAg?.totalRooms ?? s?.totalRooms ?? ... ?? 0)

    // 3) 혼잡도: rooms_biz → vendors → 자동계산
    const rbCg = byRb?.congestion
    const agCg = byAg?.congestion
    const status = s?.statusMode === 'manual'
      ? s?.status
      : (rbCg || agCg || computeStatus({ match, persons, totalRooms, ... }))

    // updatedAt: rooms_biz → vendors → stores
    updatedAt: byRb?.updatedAt || byAg?.updatedAt || s.updatedAt || null,
  })
}
```

**역할 정리**:
- 맞출방/필요인원: vendors 무관 (`rooms_biz` 또는 legacy `stores.match/persons` 사용)
- totalRooms: vendors 폴백 1순위 → 없으면 `stores.totalRooms` 사용
- 혼잡도: rooms_biz 1순위 → vendors 2순위 → 자동계산 3순위
- updatedAt: 동일 우선순위

**결론**: vendors 가 없어도 `stores.totalRooms` + 자동계산이 모두 정상 작동.

## 2. vendors 데이터 출처 — Google Sheets 시스템

### 2-1. Cloud Function `assertVendor` + `/sheets/vendors/update`

`functions/index.js:1254-1276`:
```js
// vendors/{vendorId}.savedToken 과 비교
async function assertVendor(req) {
  const vendorId = String(req.get("x-vendor-id") || "").trim();
  const vendorToken = String(req.get("x-vendor-token") || "").trim();

  if (!vendorId || !vendorToken) { throw new Error("Missing vendor headers") }
  const snap = await db.collection("vendors").doc(vendorId).get();
  if (!snap.exists) { throw new Error("Unknown vendor") }
  if (String(snap.get("savedToken") || "").trim() !== vendorToken) {
    throw new Error("Unauthorized vendor");
  }
  return vendorId;
}
```

`functions/index.js:1592-1665`:
```js
// Sheets → vendors 상태 업데이트
app.post("/sheets/vendors/update", async (req, res) => {
  const vendorId = await assertVendor(req);
  ...
  // (3) vendors/{vendorId} 요약 저장
  const vendorRef = db.collection("vendors").doc(vendorId);
  await vendorRef.set({ totalRooms, totalNeeded, ..., updatedAt }, { merge: true });

```

**흐름**:
1. Google Sheets 매크로 (GangTalkMacro?) → `/sheets/vendors/update` HTTP POST
2. 헤더에 `x-vendor-id` + `x-vendor-token` 첨부
3. Cloud Function 이 `vendors/{id}.savedToken` 과 token 비교
4. 인증 통과 시 `vendors/{id}` 본 doc + `vendors/{id}/status/*` 서브컬렉션 갱신

### 2-2. 보안 분석 — `savedToken` 노출 위험

| 시나리오 | 영향 |

## 5. 판정 — 분류

### 5-1. 본 진단의 분류

조사 4 의 3가지 분류 중:
- **(b) 실제 필요한 기능인데 룰이 막은 것** — 시트 시스템 운영 시 해당
- **(c) 무해하지만 콘솔만 더럽힘** — 시트 시스템 미운영 시 해당

→ **(b) 보안상 의도적 차단** + **(c) 콘솔 노이즈** 의 복합 케이스

### 5-2. 권장 조치 — 3 옵션

#### 방안 A — 구독 제거 (가장 단순)
**전제**: 시트 시스템 사용 안 함

수정:
- `subscribeVendorsSummary()` / `subscribeVendorStatusPerVendor()` 함수 + 호출 제거 (`MainPage.vue:1579-1748`)
- `applyRoomsBiz` 의 vendors 폴백 분기 dead 처리 (`agg` / `byAg` 참조 제거)
- `labelsMap` / `labelsAgg` ref 제거

**효과**:
- 콘솔 에러 즉시 사라짐
- 현황판 기능 영향 0 — `rooms_biz` + `stores` 만으로 정상
- 코드 ~30~50줄 감소, JS 번들 미세 감소
- **시트 시스템 재도입 시에는 코드 복원 필요**

**위험**: 0 (룰 변경 없음, 데이터 변경 없음)

#### 방안 B — `savedToken` 분리 + 룰 허용 (가장 안전한 정공법)
**전제**: 시트 시스템 운영 중

수정:
- `vendor_secrets/{vendorId}` admin-only 서브컬렉션 신규
- `vendors/{id}.savedToken` 필드 → `vendor_secrets/{id}.token` 으로 데이터 마이그레이션
- `functions/index.js assertVendor` → 새 경로 read 로 수정
- `firestore.rules` 에 `match /vendors/{id} { allow read: if true; allow write: if isAdmin(); }` 추가
- `match /vendors/{id}/status/{statusId}` 도 read 공개 룰 추가
- `match /vendor_secrets/{id}` admin-only 룰

**효과**:
- vendors 정상 구독 + 콘솔 에러 사라짐
- 기능 강화

**위험**: 
- 데이터 마이그레이션 필요 (운영 중 다운타임)
- Cloud Function 변경 + 배포
- Sheets 시스템 잠시 중단 후 재개
- 출시 직전 권장 아님 — 출시 후 검토

#### 방안 C — 에러 silent (가장 빠른 응급)
수정:
- `watchWithLabel` 의 에러 콜백에서 `err.code === 'permission-denied'` 인 경우 `console.warn` 또는 silent
- 또는 `vendors` 전용 wrapper 에서만 silent

**효과**:
- 콘솔 노이즈 즉시 제거
- 구독은 유지 — 시트 시스템 재도입 시 즉시 작동
- 단 vendors 데이터를 영원히 못 받음 (룰 부재 그대로)

**위험**: 0
**단점**: 미래의 진짜 권한 문제도 함께 가려질 수 있음 (label `vendors` 만 silent 권장)

### 5-3. 출시 전 권장

- **시트 시스템 운영 중**: 방안 C (응급 silent) + 출시 후 방안 B 검토
- **시트 시스템 미운영**: 방안 A (구독 제거) — 가장 깔끔
