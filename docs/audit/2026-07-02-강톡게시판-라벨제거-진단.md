## 0. TL;DR

- 라벨 렌더링 = **`GangTalkPage.vue` 단일 파일**의 게시판 테이블. 2 곳에서 표시:

- **데이터 소스**: 글 데이터의 `p.category` 필드 → `catLabelFor(cat)` (`:810-814`) 이 `yaCats` (`:741-748`) 배열에서 label 조회. 없으면 `'기타'` 반환

  - `<th class="col-cat">` (line 239)

- **카테고리 필터 탭 (line 210-222) / 글쓰기 모달 카테고리 선택 (line 428-439) / 상세 페이지 배지 (line 496) 는 그대로 유지** — 목록 라벨만 제거

## 2. 라벨 데이터 소스

### 2-1. 글 데이터 `p.category` 필드
- Firestore `board_posts` 컬렉션에 저장된 각 글의 `category` 필드 (문자열 키)
- 예: `'daily'`, `'suggest'`, `'pledge'`, `'vote'`, `'quiz'`, `'event'`, `'travel'`, `'health'`, `'quote'`
- 없거나 매칭 안 되면 `'default'` (마크업의 `p.category || 'default'`)

### 2-2. `catLabelFor(cat)` 함수 (`:810-814`)
```js
function catLabelFor(cat){
  return yaCats.find(c => c.key === normalizeCategory(cat))?.label || '기타';
}
```
